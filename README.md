# 👨🏻‍💻 Customer Analytics & Purchase Intelligence System

# 📌 Project Overview
This project is an end-to-end data analytics and web-based dashboard system designed to simulate real-world business intelligence workflows. It demonstrates how raw customer data can be transformed into actionable insights using Python, SQL, and an interactive web application.

# 🎯 Objective
Analyze customer shopping behavior and build an interactive system to understand purchasing patterns, customer segments, and revenue trends.

# 🚀 Key Features
- 🔐 Login system with session management
- 📊 Interactive dashboard with filters and KPIs
- 🧠 Customer segmentation (High, Medium, Low value)
- 💰 Revenue and purchasing insights
- 📈 Real-time data visualization
- 🗂️ SQL-based data analysis

# 🛠️ Tech Stack
- Python (Pandas, NumPy)
- PostgreSQL
- Streamlit
- SQL

# 📊 Dashboard Highlights
- Total Revenue, Average Purchase, Customer Count
- Sales by Category
- Gender-wise spending analysis
- Customer Segmentation distribution
- Top customers by purchase amount
